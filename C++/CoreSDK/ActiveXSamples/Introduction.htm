Configuring the Maplink Pro ActiveX Samples

1. Install MapLink Pro ... 

2. Use MapLink Pro Studio to create an output map containing your own map data.
Refer to instructions in the on-line help for how to do this. For further information please contact support@envitia.com or telephone +44 1403 273173 and ask for support.

3. Map Compression
When loading maps over an Intranet, or the Internet it is recommended that that the ‘Compress for Internet’ option be enabled in MapLink Studio.  This applies additional compression to reduce filesize and save bandwidth.

To indicate to the Controls whether the Cache needs clearing, a file ‘date.dat’ should be placed alongside the .map file on the server.  This file is checked by the control, if it is different from the file already existing in the cache, then the cache is cleared.  You should update this file whenever you update the map on the server.

4. webfiles\VBMapViewer.htm and webfiles\ActiveXCPP.htm
These HTML pages show how to embed the Visual Basic sample and Visual C++ ActiveX controls. They contain a DHTML toolbar and use JavaScript to drive the ActiveX controls.

Some of the paths in these files may need updating. You can do this by simply editing the HTML files using Notepad. The paths that you may need to update are as follows:

...
<PARAM NAME="serverMapPath" value="http://myServer/Viewer/Map">
This should point to where your map is being held.
For remote machines, this should use http addresses or UNC paths.  Local machines use standard paths.
<PARAM NAME="mapName" value="Dorset.map">
This should be the name of your map.
<PARAM NAME="persistentCacheDirectory" value="C:\WebCache">

This should be the name of a folder on the client machine, where persistently cached files are stored.
<PARAM NAME="persistentCacheSizeMaxSize" value="15">
...

4. Customisation of the Controls
The controls are supplied with full source code, enabling them to be extended.  Typical additions may be further data layers displaying more information.

5. Deployment of the Controls
When deploying the Visual Basic control, you will need to redistribute the following additional DLLs.

·         MapLinkX.dll and MapLink.dll

·         ttltgm.dll, ttltms.dll and ttltxf.dll

The Feature Rendering dialogs are independent and may optionally be shipped.  The html pages supplied show how to link them to the main viewer control.

·         FeatureRndDlgUsingCOM.ocx for Feature Rendering with Visual Basic

·         FeatureRndDlgUsingAPI.ocx for Feature Rendering with Visual C++

The Visual C++ control requires the following DLL’s.

·         MapLink.dll

·         ttltgm.dll, ttltms.dll and ttltxf.dll
