This sample is a variation of the Runtime Projection sample.

It uses a new callback on the TSLFileLoader called setLoadedCallback to allow the user to intercept data before it is used by MapLink Pro.

This therefore allows us to use the sample CreateMapCRCs to add a 32bit CRC to the MapLink Pro config directory contents and to maps generated by MapLink Studio.

The callback is created by the user. Therefore the user could add additional payload to the files read by MapLink Pro.

The use in this sample for the callback is to check the file CRC against a CRC stored at the end of the file.

The callback will work with all the File Loaders.

The user should note that with the Remote and Multi-threaded loader the callback will be in a different thread from the main thread.

In addition the user needs to keep track of when a map tile fails to load as the failure will be instigated by the user. This is important if you have enabled the all loaded callback (TSLAllLoadedCallback) as you will not receive this callback if a file has been marked as bad.
